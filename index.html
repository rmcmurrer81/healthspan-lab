Household Profiles

Personalize research without mixing family members together

Stored locally
Privacy model: profile information is stored in this browser's local storage in Version 2. It is not uploaded to GitHub or Kira Labs by this app. Browser storage is not a medical-record system and is not encrypted by this version, so do not use it for information you would not want stored on this computer.

Health Records

Give each profile better context from recent medical records

Local review workflow
Private by design: uploaded files are stored in this browser's IndexedDB for the active profile. Healthspan Lab does not commit them to GitHub. Text extraction runs in the browser, but OCR/PDF libraries and OCR language assets are loaded from public CDNs when extraction is requested. Extracted facts are drafts until you confirm them.
